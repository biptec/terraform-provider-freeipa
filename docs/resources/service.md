# freeipa_service (Resource)

FreeIPA Kerberos service principal resource. Manages only the canonical service identity. Principal aliases and `managedBy` host memberships are separate resources so one service can safely have multiple managers. Certificate/private-key material is not stored by this resource.





<!-- schema generated by tfplugindocs -->
## Schema

### Required

- `principal` (String) Service principal in FreeIPA CLI/API form, for example HTTP/app.example.test.

### Optional

- `adopt_existing` (Boolean) Adopt an already-existing canonical FreeIPA service with the same principal during resource creation instead of failing with a duplicate-entry error. Intended for controlled migration into Terraform ownership; aliases are not adopted as canonical services.
- `force` (Boolean) Force service creation when the service hostname is not resolvable in DNS. This is consumed only when a remote service must be created; changing it for an existing/adopted service does not replace the FreeIPA service.
- `skip_host_check` (Boolean) Allow creation when the service hostname does not correspond to an existing FreeIPA host object. This is consumed only when a remote service must be created; changing it for an existing/adopted service does not replace the FreeIPA service.

### Read-Only

- `id` (String) ID of the resource.
